# Analysis-everpeak
Este repositorio contiene el análisis realizado durante el Sprint 6 del caso EverPeak-SilverBasket

El datase "everpeak_retail" incluye 2,000 órdenes de clientes con valores faltantes, sentinels, outliers y problemas de calidad diseñados para simular datos reales del retail.
